# Changelog

## 1.1.0 (unreleased)

- Add an optional local EBU R128 audio measurement script for integrated loudness, true peak and loudness range.
- Add creative-direction guidance and a production-quality workflow covering speech alignment, motion-renderer boundaries and local-first integration principles.
- Preserve the Playwright/FFmpeg baseline; no new runtime dependency is introduced.

## 1.0.0 (2026-10-23)

First public release, extracted from a real hackathon submission video.

- `project-demo-video` skill: rules, phases A to J with "done when" checks, pipeline explanation, pitfalls table, QA checklist.
- Templates: screencast recorder, narration-driven director, cursor/camera overlay, terminal replay, code tour, architecture pages, captions (SRT and 1080p ASS), two-cut assembly, thumbnail, docs generator.
- Optional ElevenLabs renderer with caching and free-plan notes.
- Claude Code plugin and marketplace manifests; validation script and CI.
